# agentic_legal_rag
Production-grade agentic legal RAG stack using Next.js, FastAPI, LangGraph, Temporal, Postgres, Redis, Qdrant, OpenMemory, Zembed, and LlamaParse — containerized with Docker, deployed on AWS (ECS, RDS, ElastiCache, S3), with Clerk auth, LangSmith observability, and GitHub Actions CI/CD.
